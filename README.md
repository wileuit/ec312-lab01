# EC312 - Lab 01

E-Commerce System Design laboratory project using Docker, WordPress, WooCommerce, MySQL, Nginx and Flatsome.

## Stack

- Docker
- Nginx
- MySQL 8.0
- PHP-FPM
- WordPress
- WooCommerce
- Flatsome

## Lab Requirements

1. Install WordPress and WooCommerce
2. Install Flatsome Theme
3. Configure store information, shipping and payment
4. Add products manually
5. Import products from CSV/TXT
6. Update product price and stock manually
7. Update product price and stock using CSV import
